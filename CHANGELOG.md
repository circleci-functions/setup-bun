# Changelog

All notable changes to setup-bun will be documented in this file. Each release's section is added
by its release PR (see [RELEASE.md](RELEASE.md)) and becomes its GitHub release notes.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-24

The first release: install Bun, and `install-packages`.

### What's Changed
* Add a minimal CircleCI config and CODEOWNERS by @stiyyagura0901 in https://github.com/circleci-functions/setup-bun/pull/1
* Scaffold setup-bun from setup-node by @stiyyagura0901 in https://github.com/circleci-functions/setup-bun/pull/2
* Install Bun and put bun and bunx on PATH by @stiyyagura0901 in https://github.com/circleci-functions/setup-bun/pull/3
* Add install-packages: a frozen bun install with a package cache by @stiyyagura0901 in https://github.com/circleci-functions/setup-bun/pull/4
* Document setup-bun in the README by @stiyyagura0901 in https://github.com/circleci-functions/setup-bun/pull/5
